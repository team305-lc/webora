# サンプル整体院 ホームページ 編集ガイド

このサイトは「よく変更する項目」を1〜2か所にまとめてあります。
HTMLの知識がなくても、下記のファイルを書き換えるだけで運用できます。

---

## 1. まず最初に変更する項目

### ● 企業名・電話番号・住所・営業時間・メニュー・料金・お知らせ・お客様の声
👉 **`js/config.js`** を開いて、値を書き換えてください。

- 文字は `"` （ダブルクオーテーション）で囲みます。
- 行末の `,` （カンマ）は消さないでください。
- 変更後、ファイルを保存してブラウザを再読み込みすると反映されます。
- 全ページに自動で反映されます（各HTMLを個別に触る必要はありません）。

主な項目：

| 項目 | config.js の場所 |
|------|------------------|
| 企業名 | `company.name` |
| 英語表記（ロゴ下の小さい文字） | `company.nameEn` |
| キャッチコピー | `company.tagline` / `company.catchcopy` |
| 電話番号 | `company.tel` |
| 住所・郵便番号 | `company.address` / `company.postalCode` |
| アクセス（最寄り駅） | `company.access` |
| 営業時間・定休日 | `company.hours` / `company.holiday` |
| Googleマップ | `company.mapEmbed` / `company.mapLink` |
| メニュー・料金 | `menu`（`{ }` をコピーして増減できます） |
| お知らせ | `news`（新しいものを一番上に追加） |
| お客様の声 | `voices` |
| よくある質問 | `faq` |
| 院内ギャラリー（流れる画像） | `gallery`（`{ src, alt }` を増減） |

### ● イメージカラー（グリーン × アイボリー）
👉 **`css/style.css`** の先頭 `:root { ... }` の中の色コードを書き換えてください。

```
--color-primary:       #5b8c5a;   ← メインの色
--color-primary-dark:  #446b43;   ← 濃い色（文字・ボタンのホバー）
--color-ivory:         #f7f1e2;   ← アイボリーの背景
--color-accent:        #d8a353;   ← 差し色（予約ボタンなど）
```

色を変えたい場合は、この数値（`#` から始まる6桁）だけを変更します。
サイト全体の配色が自動で切り替わります。

※ 背景の葉っぱ模様の色だけは、同じ `:root` 内の `--leaf-pattern` / `--leaf-accent` /
　`--leaf-mini` に書かれた `%235b8c5a`（＝ `#5b8c5a`）を、新しい色コードの
　`#` を `%23` に置き換えたものに差し替えると変更できます。

## 2. ページのタイトル・説明文（SEO）の変更

検索結果に表示されるタイトルと説明文は、各HTMLファイルの上部にあります。
企業名を変更したときは、あわせて書き換えてください。

対象：`index.html` と `html/` フォルダ内の各ファイルの、以下の行

```html
<title>◯◯◯｜サンプル整体院</title>
<meta name="description" content="...">
```

`index.html` にはさらに、SNSシェア用の設定（`og:` から始まる行）と
構造化データ（`<script type="application/ld+json">` の部分）があります。
公開URLが決まったら、`https://example.com/` を実際のURLに置き換えてください。

## 3. 画像の差し替え

`img/` フォルダ内の画像を、**同じファイル名**で上書きすると差し替わります。

| ファイル名 | 使用箇所 |
|-----------|----------|
| `hero.jpg` | トップページの一番上の大きな画像 |
| `about.jpg` | トップ／整体院について／「選ばれる理由」カード② |
| `concept.jpg` | トップ／整体院について |
| `first.jpg` | トップ「選ばれる理由」カード① |
| `news.jpg` | トップ「選ばれる理由」カード③ |
| `interior1.jpg` `stone.jpg` `menu.jpg` `access.jpg` `voice.jpg` | 院内ギャラリー（流れる画像） |
| `stretch.jpg` | （予備） |

- 推奨サイズ：横 1200px 程度、JPG または WebP。
- 写真素材は著作権フリーのもの（現在は Unsplash の無料写真を使用）に差し替えてください。
- **院内ギャラリー**（トップページで右から左に流れる画像）は、実際の「外観・内装・施術風景」の写真に差し替えることを推奨します。
  枚数や順番は `js/config.js` の `gallery` で自由に変更できます（`{ src, alt }` の行を増減）。

## 4. お問い合わせフォームの設定

`html/contact.html` のフォームは、初期状態では**送信されません**。
無料サービスで送信先を作成し、URLを設定してください。

1. [Formspree](https://formspree.io/) などで無料アカウントを作成し、フォームURLを取得
2. `html/contact.html` を開き、以下の行を探す

   ```html
   <form action="#" method="POST" data-contact-form novalidate>
   ```

3. `action="#"` を、取得したURLに書き換える

   ```html
   <form action="https://formspree.io/f/xxxxxxxx" method="POST" data-contact-form novalidate>
   ```

設定が完了すると、送信ボタンで実際にメールが届くようになります。
（Googleフォームを使う場合は、フォームを埋め込む形でも構いません。）

## 5. フォルダ構成

```

├── index.html          ← トップページ
├── 編集ガイド.md        ← このファイル
├── css/
│   └── style.css       ← デザイン・イメージカラー
├── js/
│   ├── config.js       ← ★ ふだんの編集はここ

└── html/
    ├── about.html      ← 整体院について
    ├── first.html      ← 初めての方へ
    ├── menu.html       ← メニュー・料金
    ├── voice.html      ← お客様の声
    ├── news.html       ← お知らせ
    ├── access.html     ← アクセス
    └── contact.html    ← 予約・お問い合わせ
```

## 6. 公開方法

`sample` フォルダの中身をそのままレンタルサーバーにアップロードするだけで公開できます。
（ビルド作業は不要です。）

- トップページの URL は `.../index.html`（または `.../`）になります。
- 独自ドメインを使う場合は、サーバー会社の手順に従って設定してください。
- 公開後、`robots.txt` や `sitemap.xml` が必要な場合は別途ご用意ください。

## 7. 注意事項

- 本文中で「◯◯」となっている箇所は仮の文言です。実際の情報に置き換えてください。
- お客様の声は、実際にいただいた内容・許可を得たもののみ掲載してください。
- 「治る」「治療」など、医療機関と誤認される表現は避けています。文言を変更する際もご注意ください。
